# Telegram-Manager-Joiner
Fast &amp; Easily join in multiply Telegram Channels

1. Run `requirements.bat`
2. In main directory, create folder `sessions`, in this folder create 3 subfolders: `invalid`, `old` and `new`.
3. Add channels list in `channels.txt` (format - https://t.me/channel)
4. Add `.session` files in `sessions/new`
5. Run `main.py`
